## 1. 项目概述

NC 刀路查看器是一款基于 **Python 标准库 Tkinter** 的桌面工具，用于可视化查看 NC/G 代码（如海德汉、西门子等系统的 `.MPF` 文件）的加工刀路。它把逐行文本解析为 3D 刀路段，并按进给 `F` 值着色，辅助程序员直观检查刀具轨迹、定位到指定代码行的刀具位置。

### 1.1 核心能力

| 能力 | 说明 |
| --- | --- |
| NC 解析 | 处理 G0/G1/G2/G3、F 模态、G17/G18/G19 平面、G90/G91、I/J/K 圆心、N 行号、`;`/`()` 注释 |
| F 值配色 | 不同 F 进给以蛇形色相生成高区分度颜色；G0 快移为灰色；图例同步显示 |
| 圆弧离散 | 同时按「最大圆心角 0.1 rad」和「最大段长 4mm」双因素取段数，小圆弧不失真 |
| 按行定位 | 输入行号或 `N6` 形式，标出刀具实际位置（十字 + 当前段加宽高亮 + 黄色方向箭头） |
| 多文件 | 左侧文件栏一次加载多个文件，随时切换 |
| 搜索定位 | 在代码中按关键字查找并跳转，命中行高亮 |
| 程序统计 | 关键指标（X/Y/Z 行程、S/F 范围、F 档位、G 次数）+ 「详情…」完整统计二级窗口 |
| F 趋势曲线 | 「F 曲线」二级窗口：F 随行号变化折线，按 F 档位着色，min/max 参考线 |
| 视图交互 | 四元数轨道球旋转（中键）、平移（左键）、缩放（滚轮）、三视图 XY/XZ/YZ、一键适配 |

### 1.2 设计原则

- **纯计算与 UI 分离**：解析（`parser`）与几何数学（`geometry`）不依赖 Tkinter，可独立单元测试；`viewer` 只负责界面与交互。
- **渲染性能**：加载时一次性把刀路段（含圆弧）离散为 3D 点缓存（`disp3d`），旋转/平移时复用缓存，只做投影，避免重复离散。
- **TDD**：核心解析与几何算法均先写测试（`tests/`），保证重构安全。

- Python ≥ 3.8，**必须为自带 Tkinter 的版本**（本项目验证 3.8 / 3.11 / 3.14）。


### 4.1 界面布局

```
┌────────────┬──────────────────────────────┬──────────────┐
│ 文件列表    │  3D 刀路画布                  │  颜色图例      │
│ (多文件)   │  (轨道球视角)                 │  (横向流式)    │

```

顶部工具条：打开文件、适配、放大/缩小、主视图（XY/XZ/YZ）、显示 G0 快移开关。

界面采用**深色现代化主题**（`theme.py`，ttk clam 定制，VS Code 风格配色，按钮悬停高亮；纯标准库，兼容 Win7 / Tk 8.6.9）。

**颜色图例**为横向流式排布（色块 + F 文字，超出宽度自动换行）；**程序统计**面板显示关键指标（行程 X/Y/Z、S/F 范围、F 档位数、G0~G3 次数），「详情…」打开完整统计二级窗口，「F 曲线」打开 F 进给趋势折线图二级窗口。

### 4.2 鼠标与视图

| 操作 | 功能 |
| --- | --- |
| **中键按下 + 拖动** | 轨道球旋转。旋转中心取点击处最近的刀路点（12px 内吸附），否则锚定在点击处反投影点；旋转时补偿画布偏移，**点击处绝对不动**。方向跟手（右拖右转 / 下拖下转）。 |
| 左键按下 + 拖动 | 平移视图 |
| 滚轮 | 以鼠标位置为锚点缩放 |
| 适配 / 放大 / 缩小 | 一键适配、中心缩放 |
| XY / XZ / YZ | 切换主视图预设 |

### 4.3 定位与搜索

- **按行定位**：在侧栏输入行号（如 `12`）或 N 号（如 `N6`），回车后点「跳转」。画布上红色加宽高亮当前段 + 黄色箭头（直线 1 个、圆弧 3 个）表示加工方向，并显示十字与当前位置坐标。
- **上一行 / 下一行**：逐行步进。
- **搜索定位**：输入关键字点「搜索」，命中行高亮；「下一个」循环跳转。
- **代码列表**：直接点击某行即可定位。

## 6. 核心算法说明

### 6.1 NC 解析（`parser.py`）

- **词法**：`WORD_RE = ([A-Za-z])(-?\d+(?:\.\d+)?)` 提取「字母 + 数值」字；`G` 字归入 `g_codes`，其余（X/Y/Z/F/S/N/I/J/K…）存入 `word_dict`。
- **模态状态机**：逐行维护 `motion`（G0~G3）、`feed`、`spindle`（S 转速）、`plane`、`absolute`、当前坐标 `(x,y,z)`；S 与 F 同规则（G0 为 None）。
- **程序统计**：`compute_stats(result)` 返回 `ProgramStats`（X/Y/Z 行程按刀路端点计算、S/F 范围、F 档位数与各档段数、G0~G3 次数）。
- **坐标计算**：绝对模式直接赋值 / 增量模式累加；某轴未给则保留原值。
- **圆弧**：`center = start + (I,J,K)`，`cw = (G2==True)`。
- **移动生成条件**：存在运动指令且有坐标变化（`has_coord`）。
- **位置跟踪**：每行记录执行后位置到 `line_positions[行号]`，供按行定位；`position_at_line` 对越界行号取首/末值。
- **N 号映射**：`N 值 → 文件行号`，长程序 N 重启时取**首次出现**。

### 6.2 圆弧离散（`geometry.arc_points`）

针对 G2/G3，按所在平面把圆弧参数化到 `(a,b,c)` 坐标，计算圆心角 `sweep` 与半径 `r`。
- 段数 `n = max( n_angle, n_len )`，其中
  - `n_angle = sweep / 0.1`（每段最大 **0.1 rad**，保证曲率）
  - `n_len = arc_len / 4`（每段最大 **4 mm**，大圆弧控制精度）
  - 上限 `max_steps = 240`，下限 `≥ 1`。
- 取两者**较大值**：小圆弧（如 r ≥ 1 mm）因角度项被离散为多段而显示曲率，避免退化成直线。

### 6.3 轨道球旋转（`geometry.orbit_rotate`）

- 鼠标水平拖动 `dx` 绕屏幕垂直轴、垂直拖动 `dy` 绕屏幕水平轴，构造视空间增量四元数 `dq`。
- 用**前乘** `dq * quat` 叠加，使旋转在**屏幕空间**进行，方向天然跟手。
- `compensate_center` 计算旋转前后旋转中心投影差，补偿画布偏移，确保点击中心在屏幕上绝对不动。

### 6.4 渲染（`viewer.render`）

- 内联四元数 `quat_rotate` 投影所有离散点，`_disp3d` 缓存避免重复离散。
- 相邻同色折线合并为 `create_line` 扁平坐标列表，减少 Canvas 对象数量。
- 当前段：红色加宽高亮（`SEG_COLOR`）+ 黄色三角箭头（`_draw_move_direction`，直线 1、圆弧 3）。

## 8. 常见问题（FAQ）

**Q：`import tkinter` 报错？**
A：当前解释器未捆绑 Tkinter。用 conda `python38` 环境或 `py -3.11` / `py -3.14` 运行。

**Q：`ModuleNotFoundError: No module named 'nc_viewer'`？**
A：需先 `pip install -e .`，或用 `python -m nc_viewer` 且按本手册安装。

**Q：命令行能传多个文件吗？**
A：不能。命令行仅支持单文件；多文件请用界面「打开文件…」多选。

**Q：小圆弧仍显示为直线？**
A：确认使用最新 `arc_points`（段数取角度与弧长较大值）。旧版本仅按段长控制会退化为直线。

**Q：旋转会"发飘"吗？**
A：已通过 `PICK_MAX_PX=12` 像素吸附 + `compensate_center` 补偿，点击处绝对不动。若点击处无刀路点，则锚定到点击处反投影点（包围盒 Z 中心深度）。

**Q：能在 Windows 7 上运行吗？**
A：可以（64 位 Win7）。须用 conda 的 Python 3.8 环境运行 `build_exe.bat` 打包（PyInstaller 5.x，bat 自动处理），产物已内置 UCRT，裸装 Win7 无需补丁。注意 Python 3.9+ 构建的 EXE 无法在 Win7 运行。

**Q：Win7 上提示缺少 DLL（如 api-ms-win-crt）？**
A：说明用的是旧版或非 conda 构建，未内置 UCRT。请用 `build_exe.bat`（自动走 conda python38 分支）重新打包，并确认日志出现「内置 UCRT 运行时」。

## 10. 注意事项（开发 / 运行 / 使用 / 打包）

> 本章汇总本项目所有**必须注意**的事项，改动与使用前请先通读。

### 10.1 运行环境
- 必须使用**自带 Tkinter** 的 Python（验证 3.8 / 3.11 / 3.14）；无 Tkinter 的解释器无法运行。
- **Win7 目标**：构建解释器必须是 conda 的 Python 3.8；3.9+ 构建的 EXE 无法在 Win7 运行。
- 命令行仅支持加载**单个**文件；多文件请用界面「打开文件…」多选。

### 10.2 开发约束
- **纯计算与 UI 分离**：`parser`、`geometry` 不得 `import` Tkinter，保证可独立单测。
- **TDD**：先写测试 → 实现 → 全绿（green）→ 再打包；每次改动都应有对应测试。
- **最小改动**：只改任务所需，不顺手重构无关代码。

### 10.3 运行/使用注意
- **性能**：大程序（如 2.5 万＋刀路段）加载时一次性离散并缓存刀路点（`disp3d`），旋转/缩放复用缓存，请勿在渲染中重复离散。
- **圆弧**：小圆弧也应按曲率显示；若显示为直线，确认 `arc_points` 使用角度+弧长双因素段数。
- **旋转手感**：旋转中心取点击处 12px 内最近刀路点，否则锚定点击处反投影点；点击处无刀路点时旋转中心位于包围盒 Z 中心深度。

### 10.4 打包注意
- 打包入口必须是**`launcher.py`**（`__main__.py` 用相对导入，不能直接作为 PyInstaller 入口）。
- `build_exe.bat` 需保持 **CRLF 换行**（LF 会导致 cmd 解析丢首字符）。
- 新增数据/资源文件需通过 `--add-data` 一并打包。
- **Win7 目标**：必须用 conda `python38`（Python 3.8）构建，且 PyInstaller 必须为 **5.x**（6.10+ 的 bootloader 不支持 Win7）；bat 会自动探测 conda python38 并固定 PyInstaller 5.13.2。
- **Win7 裸机运行**：conda 构建时 bat 自动把 UCRT（`ucrtbase.dll` + `api-ms-win-crt-*.dll`）打包进 EXE，目标 Win7 无需安装 KB2999226 补丁。
- 构建解释器可显式指定：设置环境变量 `NCVIEWER_PY`（python.exe 完整路径）。
- **发布前**：全量测试 green + EXE 冒烟测试通过（Win7 目标还须在真实 Win7 机器上实测）。
