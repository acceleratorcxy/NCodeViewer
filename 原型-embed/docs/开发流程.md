# 开发流程规范

> 适用项目：NC 刀路查看器 Qt 离屏渲染实验版（原型-embed，NCodeViewer 渲染实验分支）
> 作用：**严格遵循**的开发 / 测试 / 打包 / 发布流程。任何流程本身的变更，也须同步维护到本文档。

---

## 1. 核心原则

1. **TDD 先行**：先写（或更新）测试 → 让测试 FAIL（红）→ 实现使其 PASS（绿）→ 再打包/发布。
2. **每次改动都有测试**：任何代码/界面改动都应有对应测试用例保护，防止回归。
3. **绿灯后才打包**：`pytest` 全绿（green）之前，不执行打包、不发布 EXE。
4. **最小改动**：只改任务所需，不顺手重构无关代码。
5. **变更留痕**：所有改动同步写入 `CHANGELOG.md`。
6. **渲染质量优先**：刀路显示**不得抽稀、不得断线**（全量合并折线）；任何导致刀路无法看清的方案直接否决。

---

## 2. 环境要求

| 项 | 要求 |
| --- | --- |
| Python | ≥ 3.8：**必须自带 Tkinter**（验证 3.8 / 3.11）；**Win7 目标构建必须用 conda 的 Python 3.8**（3.9+ 不支持 Win7） |
| 运行时依赖 | `PyQt5>=5.15,<5.16`、`numpy`、`Pillow`（**Win7 目标**：numpy<2、Pillow<11，PyQt5 5.15.x 为最后支持 Win7 的 Qt5 版本） |
| 测试依赖 | `pytest`（3.8 环境需 `<9`） |
| 打包依赖 | `PyInstaller`（脚本会自动安装；Win7 构建须为 **5.x**，bat 自动固定 5.13.2） |

> 排查：`import tkinter` 报错 → 当前解释器未捆绑 Tkinter，改用 conda `python38` 环境或 `py -3.11`。
> 排查：`import PyQt5` / `import numpy` / `import PIL` 报错 → 未安装运行时依赖，`python -m pip install "PyQt5>=5.15,<5.16" numpy Pillow`。

## 3. 目录与模块约定

```
src/nc_viewer/
├── parser.py         # NC/G 代码解析（纯计算，不依赖 Tkinter）
├── geometry.py       # 几何数学（纯计算，不依赖 Tkinter）
├── theme.py          # 深色现代化主题（配色/字体常量 + apply_theme）
├── tool.py           # 刀具模型（纯计算，不依赖 Tkinter）
├── qt_offscreen.py   # Qt 离屏渲染器（QOffscreenSurface + FBO + VBO + overlay）
├── viewer.py         # Tkinter 主窗口（NCViewer，画布渲染接入 qt_offscreen）
├── __main__.py       # python -m nc_viewer 入口
└── __init__.py       # 包接口（NCViewer 延迟导入）

tests/                # pytest 用例
docs/                 # 技术手册、开发流程
CHANGELOG.md          # 更改记录
launcher.py           # PyInstaller 打包入口
build_exe.bat         # 打包脚本
```

- **纯计算与 UI 分离**：`parser`、`geometry`、`tool` 不得 `import` Tkinter / PyQt5，保证可独立单测。
- **渲染分层**：`qt_offscreen` 只做 GPU 渲染（VBO 构建、MVP、overlay），`viewer` 负责 Tk 界面、交互与状态（`_trace_drawn` 等），两者经 `set_result / set_tool / render` 接口通信。
- 新增逻辑优先放入对应模块；若属纯计算，写进 `geometry` / `parser`；若属 GPU 绘制，写进 `qt_offscreen`。

## 4. 开发 / 测试流程

### 4.1 标准步骤（每次改动）

```bash
# 1) 写/更新测试（RED）
#    在 tests/ 下新增或修改对应测试用例

# 2) 运行测试，确认针对新功能是失败的（可选，验证测试有效）
python -m pytest -q

# 3) 实现功能（GREEN）
#    修改 src/nc_viewer/ 下对应模块

# 4) 全量回归，必须全部通过（py38 + py311 双环境）
<conda38-python> -m pytest -q
py -3.11 -m pytest -q

# 5) 更新 CHANGELOG.md
```

### 4.2 测试命令

```bash
# 全量测试
python -m pytest -q

# 指定文件
python -m pytest tests/test_qt_offscreen.py -q

# 指定用例（-k 关键字）
python -m pytest -k "trace" -q
```

> `pyproject.toml` 已配置 `testpaths=["tests"]`、`pythonpath=["src"]`，无需安装即可跑测试。
> 注意：本目录自带 `pyproject.toml`，pytest 以此为 rootdir；若删除它，pytest 会向上找到主程序的 pyproject 并错误导入主程序 `src`。

### 4.3 测试覆盖要求

- 解析逻辑（`parser`）：G0/G1/G2/G3、F 模态、平面、绝对/增量、N 行号、位置跟踪、注释容错、真实样例。
- 几何逻辑（`geometry`）：轨道旋转方向、四元数规范性、旋转中心不动、圆弧离散。
- 离屏渲染（`qt_offscreen`）：**全量 VBO 不抽稀**（顶点数 = 段数×2）、**seg_map 逐移动精确**（播放渐进粒度，回归"一段颜色执行完才显示"）、G0/段过滤、渲染帧尺寸格式、FBO 随画布尺寸重建、trace 裁剪渲染。
- 界面结构（`viewer`）：UI 改动需附回归测试；Qt 渲染接管后，涉及 Tk 画布图元的断言应改为断言离屏路径（`_trace_drawn` 状态、`_qt_render` 触发、`_renderer` 状态传递）；无显示环境（CI）用 `pytest.skip` 跳过。

### 4.4 Qt 离屏渲染注意事项（改动前必读）

- **初始化时序**：`QApplication` 创建后**立即**创建 `QOffscreenSurface` 会访问违规崩溃（Qt 5.15 平台初始化时序）；viewer 以 `after(150)` 延迟初始化天然规避，测试需显式 `processEvents + sleep` 等待。
- **PhotoImage 复用**：播放每 tick 更新像素用 `paste` 复用同一 PhotoImage；**禁止每帧新建**（Tk 图片对象累积 → 越用越卡）。
- **seg_map 语义**：`seg_map[i]` = 移动 i 完成后的**真实累计段数**（已落库 + 当前折线段数）；合并进同色折线的移动必须实时计入，否则播放时整段不显示。
- **data 版本 key**：VBO 重建条件 key 必须覆盖所有影响几何的输入（result/段过滤/G0/刀具/刀具开关），漏一项 → 切换不生效。
- **残留图元**：Qt 接管渲染后 Tk 侧不再产生刀路/标记图元；`render()` Qt 分支会清理回退残留（`path/cur/curx/curseg/toolmodel`），勿在此画 Tk 图元。
- **不抽稀**：VBO 为全量合并折线（同色连续 + 共享端点合并，段数不减）；渲染裁剪只在播放渐进时按移动边界截断。

## 5. 打包流程

### 5.1 前置条件

- [ ] 全量测试 green（py38 + py311）
- [ ] EXE 冒烟测试通过（见 5.3）

### 5.2 执行打包

```bash
# 方式一（推荐）：运行打包脚本 build_exe.bat
# 或 .\build_exe.bat
```

`build_exe.bat` 自动探测构建解释器，顺序为：
1. 环境变量 `NCVIEWER_PY`（python.exe 完整路径）显式指定
2. conda `python38` 环境（**Win7 目标构建优先**）
3. `py -3.11`（Win10/11 构建）

用 conda python38 构建时：自动固定 PyInstaller 5.13.2（6.10+ 的 bootloader 不支持 Win7），并把 UCRT 运行时打包进 EXE，裸装 Win7 无需 KB2999226 补丁。

```bash
# 方式二：手动 PyInstaller 命令（Win7 目标示例，用 conda python38）
<conda38-python> -m PyInstaller --onefile --windowed --name NCViewer --paths src --add-binary "<conda38-root>\ucrtbase.dll;." --clean launcher.py
```

输出：`dist\NCViewer.exe`（单文件、无控制台）。

> **注意**：本实验版运行时依赖 PyQt5/numpy/Pillow，PyInstaller 需能收集其 DLL（PyQt5 的 Qt5Core.dll 等在 `--collect-binaries` 之外默认可收集，如有缺失用 `--collect-all PyQt5`）；Win7 目标的依赖版本约束见第 2 节。

### 5.3 冒烟测试（打包后必做）

```bash
# 启动 EXE，确认进程存活（非立即崩溃）
$p = Start-Process "dist\NCViewer.exe" -PassThru
Start-Sleep -Seconds 4
if ($p.HasExited) { "FAIL code=$($p.ExitCode)" } else { "OK"; Stop-Process $p.Id -Force }
```

### 5.4 打包注意事项

- 打包入口必须是 `launcher.py`（`__main__.py` 使用相对导入，不能直接作为 PyInstaller 入口）。
- `build_exe.bat` 需保持 **CRLF 换行**（bat 文件用 LF 会解析丢字符）。
- 若改动涉及新数据文件，需通过 `--add-data` 一并打包。
- **Win7 目标**：构建解释器必须是 Python 3.8（conda `python38`），PyInstaller 必须是 **5.x**；运行时依赖须用支持 Win7 的版本（PyQt5 5.15.x、numpy<2、Pillow<11）。
- **Win7 实测**：本机（Win10/11）冒烟通过 ≠ Win7 可运行，发布前必须在真实 Win7 机器上打开样例文件验证渲染/旋转/定位。
